# Data Directory

## What is included in this repository

| File | Size | Description |
|------|------|-------------|
| aoi_EMSR850.geojson | ~2 KB | Bounding box of flood AOI |
| copernicus_ref/EMSR850_ALL_DEL_observedEvent_merged.gpkg | ~1 MB | Merged flood reference polygons |

## What is NOT included (too large for GitHub)

| Data | Size | How to get it |
|------|------|---------------|
| sentinel1/ | ~3.4 GB | Download via script 02 + 03 using CDSE API |
| sentinel2/ | ~1.5 GB | Export via script 04 using Google Earth Engine |
| dem/ | ~50 MB | Export via script 05 using Google Earth Engine |
| meteo/ | ~5 MB | Export via script 06 using Google Earth Engine |
| exposure/ | ~20 MB | Export via script 07 using Google Earth Engine |
| processing/ | ~20 GB | Generated by script 08 (SNAP processing) |

## How to reproduce the full dataset

1. Register at https://dataspace.copernicus.eu/
2. Register at https://earthengine.google.com/
3. Add credentials to ~/project_EMSR850/cdse_credentials.json
4. Run scripts 01 to 10 in order
